# Innovation Diffusion Analysis Using the Bass Model

## Project Overview

This project analyzes innovation diffusion using the Bass Model. The selected innovation is the Unitree R1 humanoid robot, featured in TIME's Best Inventions of 2025.

Since historical sales data for the Unitree R1 is limited, worldwide industrial robot shipments are used as reference data to estimate the model parameters. The project also explores possible future developments in the humanoid robot market using three illustrative scenarios.

## Project Files

- `bass_model_homework.ipynb` — Python code and analysis.
- `industrial_robots.csv` — Historical industrial robot shipment data.
- `humanoid_robot_scenarios.csv` — Results for the humanoid robot diffusion scenarios.
- `industrial_robot_bass_fit.png` — Graph showing the Bass Model fit for industrial robot shipments.
- `industrial_robot_forecast_2025_2040.csv` — Industrial robot forecast file.
- `unknown.png` — Additional image file.
- `report.pdf` — Final report describing the methodology, results, predictions, and limitations.

## Data Sources

- TIME — Unitree R1, Best Inventions of 2025.
- Statista / International Federation of Robotics (IFR) — Worldwide industrial robot shipments.
- Bank of America Institute — *Physical AI, Part 2: Humanoid Robots*.

## Limitations

The humanoid robot scenarios are based on assumptions and model estimates. They describe possible market developments and should not be interpreted as exact predictions of Unitree R1 sales.
