# bass-model-homework
# Innovation Diffusion Analysis Using the Bass Model

This project analyzes innovation diffusion using the Bass Model.

The selected innovation is the Unitree R1 humanoid robot, featured in TIME's Best Inventions of 2025. Since historical sales data for this specific robot is limited, worldwide industrial robot shipments are used as a reference for estimating the model parameters.

The project includes historical data analysis, Bass Model estimation, and three illustrative scenarios for humanoid robot market diffusion.

## Files

- `bass_model_homework.ipynb` — Python code and analysis.
- `report.pdf` — Final project report.


## Data Sources

- TIME — Unitree R1, Best Inventions of 2025.
- Statista / International Federation of Robotics (IFR) — Worldwide industrial robot shipments.
- Bank of America Institute — *Physical AI, Part 2: Humanoid Robots*.

The humanoid robot scenarios are illustrative model estimates, not forecasts of Unitree R1 sales specifically.
